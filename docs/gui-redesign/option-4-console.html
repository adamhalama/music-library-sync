Option 4 — Console

The TUI, promoted. Dense, sortable, keyboard-driven, one flat table across every source, and a live command bar that shows exactly which udl invocation the GUI is about to run. Fastest for someone who already knows the tool.

Table(selection:sortOrder:)
SwiftUI Table with KeyPathComparator sorting — column headers sort natively, no custom code.
.monospaced() / .font(.system(.body, design:.monospaced))
Numeric and identifier columns stay aligned; titles stay in SF for readability.
.onKeyPress / .keyboardShortcut
macOS 14 onKeyPress gives the j/k/space/a/n bindings from the TUI verbatim.
.toolbar(.automatic) control strip
All run options live in one 38pt strip as Stepper, Picker(.segmented), Toggle(.checkbox). No panel, no popover.
Bottom “formula bar”
Detail line for the focused row — remote URL, target path, status reason. Replaces per-row disclosure.
Command bar
Copyable text of the equivalent CLI call. Keeps the GUI honest and teaches the CLI.
