Track limit

How many tracks udl pulls from this source before planning. 0 means everything.

Plan window

Which end of the playlist to read. Spotify + deemix only — scdl has no window switch.

Run mode

A dry run resolves every selected track and reports what would happen, without writing files or updating state.

Option 5 — Guided

Reviews one source at a time, the same way udl sync --plan actually runs. Fewest decisions on screen at once; best for occasional use and for the first run after setup. Slowest for a five-source library.

NavigationStack + path
Each step is a pushed view; the step bar is a custom header bound to path.count. Back is free.
TabView(.page) for sources
Per-source review pages with the dot indicator — swipe or Continue moves to the next source. Mirrors the CLI's per-source selector loop.
.popover on chips
Settings are shown as their values, not their controls; tapping a chip opens a small popover to change one thing.
List(.insetGrouped-ish)
Rounded card list, 48pt rows, generous hit targets. Toggle per row with .toggleStyle(.checkbox).
ProgressView(value:)
Footer shows how far through the sources you are — the review itself has visible progress.
.defaultAction / .keyboardShortcut(.return)
Continue is the default button; ⏎ advances all the way to the run.
