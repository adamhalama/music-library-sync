Credentials

A status board rather than a form. Each credential shows health, where the running value actually comes from, what breaks without it, and exactly one obvious action.

Table + custom row
Four columns: credential, health pill, affected workflows, storage source.
SecureField in a sheet
Values are entered in a modal .sheet, with an explicit "show value" toggle. Nothing sensitive is ever rendered in the main window.
Keychain Services
Save/update/clear map to SecItemAdd / SecItemUpdate / SecItemDelete; the GUI never touches the YAML files.
External override state
When an env var wins, the row is marked and the action becomes "Move to Keychain" instead of "Update" — the UI never lies about which value runs.
