Settings

This screen owns app-level preferences only: window behavior, appearance, notifications, and shortcuts. Workflow behavior remains explicit and portable in the YAML editors.

Settings scene
In SwiftUI this becomes a dedicated Settings scene, accessible from the app menu with the standard shortcut.
@AppStorage
Lightweight preferences persist automatically without touching workflow configuration.
System integrations
Notifications and updates request permission only when first used; no background agent is installed implicitly.
