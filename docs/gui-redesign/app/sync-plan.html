Sync Plan

The screen that replaces udl sync --plan's per-source terminal selector. Sources stay in the sidebar, the plan is a real table, and every run option is visible without leaving the screen.

Table(of: PlanRow.self, selection:)
Sortable columns, Set<PlanRow.ID> selection, alternating row backgrounds. 26pt rows.
Toggle(.checkbox)
Row checkbox is disabled when !row.toggleable — already_downloaded rows can never be queued.
Picker(.segmented)
Status filter in the toolbar; plan window in the inspector with .disabled(!source.supportsWindow).
Stepper + TextField
Plan limit, mirroring the TUI [ / ] / l / u bindings.
.searchable(placement:.toolbar)
Title/artist filter.
.safeAreaInset(.bottom)
Status bar totals across every enabled source, not just the visible one.
